# TechnoUltra

Plataforma PWA para clientes, técnicos y administración de TechnoUltra (servicio técnico, tienda y proyectos digitales).
Stack: Next.js (App Router) · TypeScript · Tailwind · Supabase · Vercel.

## Empezar

```bash
cp .env.example .env.local   # completa los valores; nunca subas .env.local
npm install
npm run dev                  # http://localhost:3000
npm run check                # typecheck + lint + tests + build
```
